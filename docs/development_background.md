# 项目沿革与当前开发背景

本仓库对应**知意随行——基于多模态意图理解与具身空间推理的辅助取物机器人**，沿用RoboFlex工程名称。

## 已有基础与本轮方向

项目从手势控制移动抓取原型发展而来，已有传感手套、嵌入式控制、移动抓取实拍、相关实用新型专利与手势交互研究基础。已有原型可抓取空水杯、纸盒、网球、乒乓球和生鸡蛋；约83%为原型抓取成功率，约90 ms为良好网络下视频传输延迟，约3000元为原型成本。后续工程沿用这些事实各自的测量对象，不将其外推为新系统性能。

当前方向是将**多模态意图理解与连续移动操作结合**。操作端以视频、柔性弯曲传感及IMU表达非语言意图；云端VLM形成语义目标与任务建议；任务管理绑定实体、目标版本与完成条件；执行系统结合动作策略、可靠性感知时空规划与相位反馈，完成短距离轻小件取送。

项目依托连续移动操作合作研究基础开展场景衔接，原始方法保留研究署名。合作研究中的观测窗口、可达补偿余量和相位控制构成完整系统的重要部分。其完整优化器与研究平台驱动不因本仓库提供参考实现而被描述为未开展，也不将开源基线冒充完整优化器。

## 迁移材料采用的基准

本次开发读取了项目迁移后的“知意随行_定名版”资料，采用其中最新“07_架构图更新版”的系统方案、接口和方法来源。该版本比赛材料为21页，第8页是可编辑系统架构图；“04_技术叙事修订版”记录技术主线和合作研究表述的修订；“05_提交定稿”与“06_GitHub上传”保留对应提交和工程背景。

这些背景材料明确了三点：

1. 产品服务行动不便者及照护家庭，首款范围为单一生活区域、短距离、轻小件及预设交接点。
2. 模型、任务、动作与规划的职责贯通，同时保留目标ID、坐标、时间、版本与完成证据。
3. 相位控制不仅是离散阶段名称，还包括随相位调整跟踪与任务误差作用、约束内参考修正和重新规划。

本仓库的模型提供器按实际API配置，不在代码中假设某个产品称谓就是有效模型ID。竞赛叙事、完整研究系统和开源可复现实验的范围分别说明，便于协作开发。

## 本次开源工程的定位

在保留原有摄像头意图基线、协议桥和历史素材的基础上，新增：

- 操作端／机器人视频与手套特征的统一时序窗口。
- 可配置VLM提供器及带新鲜确认流程的HTTP意图服务。
- 单次取放的Task Token、空间绑定、有效期、幂等与目标版本检查。
- 麦轮参考运动映射、四轴参考机构与MuJoCo状态闭环。
- 取消、失联、目标移动及路径失败情景，日志和仿真视频导出。

当前Task Token表达一次取放；完整连续多任务框架还包含步骤依赖、活动任务窗口、恢复分支与任务账本。两者通过[接口契约](system_interfaces.md)衔接。VLM负责理解目标，VLA候选由对应动作策略适配，当前参考执行以几何基线运行。

最新硬件采用ESP32、柔性弯曲＋IMU、树莓派、广和通4G、麦轮底盘、舵机及柔性机械爪。历史照片记录ESP8266等早期配置，保留原图说明演进。柔性结构提供被动顺应性，无力传感器时不宣称测得夹持力反馈。

当前无硬件阶段以[真实输入采集与MuJoCo验证](no_hardware.md)继续开发；生成式概念视频用于愿景表达，实际任务验证使用可追溯的执行状态和结果。
