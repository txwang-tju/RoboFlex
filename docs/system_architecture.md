# 知意随行——基于多模态意图理解与具身空间推理的辅助取物机器人

## 1. 项目定位与技术主线

知意随行面向行动不便者及照护家庭，以多模态意图理解驱动连续移动操作。系统结合GPT-6对图像与用户意图的理解，将取物需求组织为有完成条件的任务序列，再通过动作策略、可靠性感知的时空全身规划和相位依赖切换控制，协调移动底盘与机械臂完成接近、抓取、携行、放置和结果核验。

本项目围绕连续操作的可靠性、任务效率与兼容适配开展系统设计，并结合连续移动操作合作研究推进应用。多任务指按依赖顺序完成多步操作和连续取放。全身指底盘与机械臂协同。连续执行通过协调运动减少不必要的停稳和重复定位，遇到遮挡、撤回或故障时按任务状态暂停与恢复。

首个应用场景为单一生活区域内的短距离轻小件取送，使用预设交接点与托盘。用户表达并确认目标后，系统承担后续操作，减少持续遥控的负担。

## 2. 连续操作的关键矛盾

| 问题 | 对连续操作的影响 | 对应机制 |
|---|---|---|
| 运动速度与观测时间冲突 | 接近过快，目标位姿尚未更新就进入抓取 | 将目标可见性和有效观测时长纳入规划 |
| 路径效率与纠偏能力冲突 | 机械臂接近可达边界，目标稍有偏差便无法补偿 | 为任务位姿附近的误差修正保留可达余量 |
| 长时域规划与实时反馈冲突 | 全局轨迹生成后，目标或定位结果仍会变化 | 相位依赖反馈与参考修正衔接规划和执行 |
| 多步任务的状态不一致 | 抓取未成立便进入运输，旧动作接到新目标 | 以完成条件、目标版本与任务账本控制推进 |
| 模型与硬件动作定义不同 | 动作维度、单位或坐标不匹配导致执行错误 | 统一接口、动作映射和平台约束检查 |

可靠性在本项目中体现为：任务在观测与执行偏差下仍有可用的纠正条件，并通过反馈核验每一步结果。效率以整条任务链的总耗时评价，同时记录等待、停顿、重规划和人工介入。

## 3. GPT-6、动作策略与规划控制的协作

GPT-6位于语义理解与高层任务规划环节，接收图像、手物关系及连续行为摘要、任务上下文，输出候选目标或任务步骤。场景模块结合RGB-D深度和相机标定，为语义目标关联稳定的物体ID、位置与坐标系。任务管理对目标、步骤顺序、前置条件和完成条件进行绑定与检查。

VLA动作策略接收观测、本体状态及目标条件，形成动作候选或短时动作片段。平台适配器统一动作定义，规划模块检查可达性与任务约束，并形成底盘和机械臂的连续参考。相位控制依据实时反馈进行跟踪、纠偏和完成核验。GPT-6输出的目标与步骤通过这条执行链转化为机器人动作。

本项目采用分层的视觉、语言与动作系统架构。GPT-6承担图像与意图理解；动作策略型号、权重、动作空间与执行频率由实际平台配置记录。几何策略保留为参考执行方式，用于接口调试与同任务对照。

## 4. 系统闭环

| 模块 | 主要输入 | 主要输出 |
|---|---|---|
| 感知与状态 | RGB-D、手部关键点、可选弯曲／IMU、本体状态 | 候选物体、手物关系、位姿、时间与传感有效性 |
| GPT-6理解与意图融合 | 图像、连续行为摘要、历史任务上下文 | 目标候选、语义步骤、意图状态与撤回事件 |
| 任务管理 | 已确认目标、空间实体与执行反馈 | 任务账本、步骤依赖、完成条件、恢复分支 |
| 动作策略与平台映射 | 目标条件、观测与机器人状态 | 带动作语义、坐标、时间和有效期的候选 |
| 时空全身规划 | 活动任务、场景、本体状态与动作候选 | 底盘轨迹、关节轨迹、阶段时长与相位参考 |
| 相位反馈控制 | 全局参考、在线目标估计与实时误差 | 约束内的控制指令、状态回传、核验与停止事件 |

感知持续更新场景，执行反馈持续更新任务账本。当前步骤完成后，活动任务窗口向后推进，规划器结合新状态衔接后续操作。目标变化或旧策略输出过期时，相关候选失效。停止、有效期和设备状态检查由本地执行链处理。

## 5. 意图驱动的任务组织

用户伸手、指向或改变动作方向时，系统综合手物空间关系、动作趋势与上下文保留目标候选。相邻物体或线索不足时继续观察，同时保留“暂无操作意图”。视觉提供目标空间信息，可选手部传感补充细微动作与阶段线索。用户通过适合自身能力的入口确认目标，随后锁定目标ID、交接点与目标版本。

以收走空瓶为例，任务依次组织为：

| 步骤 | 前置条件 | 完成证据 | 恢复方式 |
|---|---|---|---|
| 目标确认 | 目标候选与空间信息有效 | 用户确认，目标与交接点锁定 | 继续观察或取消 |
| 接近与抓取 | 路径、可达性与目标定位有效 | 硬件夹持状态或视觉变化支持抓取成立 | 重定位、重新接近或接管 |
| 携物移动 | 物品保持受控 | 到达交接区域，物品状态有效 | 暂停、重规划或接管 |
| 放置与交接 | 交接点和释放条件有效 | 物品进入交接点并与夹爪分离 | 再核验或受限重试 |
| 任务验收 | 放置结果已核验 | 更新任务账本并退出任务 | 保留未完成步骤 |

任务账本记录task_id、目标ID与版本、当前步骤、完成证据、重试次数和失败原因。ACK表示通信接收状态，完成事件还需对应实际动作或物体证据。夹持检测采用平台实际具备的传感与状态信息。

## 6. 可靠性感知的时空全身规划

规划联合考虑底盘位姿、机械臂关节轨迹和任务阶段时长。方案层的统一表达为：

    决策变量：底盘轨迹 b(t)、机械臂关节轨迹 q(t)、各阶段时长 Δt
    优化目标：任务总时长 + 轨迹平滑与控制变化代价
    约束条件：运动学、速度与关节范围、避障、任务依赖、
              有效观测窗口、可达补偿余量、抓放交互条件

目标函数的权重和约束参数根据机器人与任务标定。该表达说明规划变量与约束之间的关系，具体求解器与参数由研究平台配置。

**有效观测窗口。** 机器人接近目标期间保持可用视角，并为定位算法留出足够的有效观测时间。规划同时考虑目标可见性、观测质量与感知处理延迟，使位姿更新赶上后续操作。

**可达补偿余量。** 规划除检查名义任务位姿，还考虑其附近一定偏差范围内的可达性。底盘位置与机械臂构型共同保留纠偏空间，使在线定位更新后仍有运动余量完成修正。补偿范围依据误差特征与平台可达空间设定。

**抓放交互结构。** 接近、抓取、放置与退出具有不同的末端要求。规划协调必要接触与环境避障，保留适合抓放的接近和退出方向，减少无效停顿，同时满足运动和交互约束。

**连续任务衔接。** 在活动任务窗口内联合安排多个步骤的底盘位置、机械臂动作与时间，减少分开规划产生的等待和重复定位。反馈更新后滚动调整轨迹，衔接下一项操作。

## 7. 相位依赖切换控制

全局轨迹给出长时域的高效运动参考，局部反馈处理规划后出现的目标位姿更新与跟踪误差。相位控制根据任务执行阶段调整两者的作用：

| 任务相位 | 反馈重点 |
|---|---|
| 移动与接近 | 跟踪全局参考，协调底盘与机械臂，并保持目标观测 |
| 临近目标 | 更新相对位姿，平滑增强末端任务误差反馈 |
| 抓取与放置 | 在约束内补偿任务误差，保持接近与退出结构，核验交互结果 |
| 退出与续行 | 平滑衔接全局参考与下一阶段动作 |

控制目标可用“随相位变化的轨迹跟踪代价、任务误差代价和控制平滑代价”表示。权重连续变化，控制指令在平台约束内求解。在线目标更新通过局部参考修正进入执行链，保持运动衔接和原有交互要求。

局部误差超过补偿余量、目标观测失效或可达性变化时，控制器请求重新规划。任务管理依据返回状态决定等待、重试或接管。用户撤回后保留物品受控状态；急停按照硬件复位流程恢复，并重新核验机器人与物体状态。

## 8. 模型与平台兼容适配

兼容性通过明确的接口和平台模型实现。模型侧统一输入场景、目标条件和输出动作语义。硬件侧配置底盘运动学、机械臂自由度、工具偏置、关节范围、速度与传感布局，再完成动作映射与可达性检查。

差速底盘在规划中加入非完整运动学约束。四轴机械臂按其可控位置与姿态分量设置任务。更换机械臂或传感器时，更新本体模型、标定与适配器，并用相同任务执行接口回归。

接口共享task_id、时间戳、坐标系、目标版本和有效期。角度、长度和速度单位在适配器集中换算。VLA动作候选明确采用关节位置、速度或末端增量中的哪一种定义。详细字段见system_interfaces.md。

## 9. 验证方法与指标

连续操作以整条任务链的成功与总耗时为核心指标，同时记录非必要停顿、重试、重规划、物品失控和人工介入。意图理解补充评价目标判断、自然动作误触发、确认负担和撤回响应。

对照实验保持意图输入、物体、目标与环境一致，比较逐段停稳执行与完整连续方案，并分别去除观测时间约束、补偿余量约束或相位切换，检验各机制的作用。模型与平台适配采用相同任务的接口回归和结果对照，记录部署参数与适配工作量。

原型实拍展示空水杯、纸盒、网球、乒乓球和生鸡蛋抓取。约83%为该原型抓取成功率，约90ms为良好网络下视频传输延迟，约3000元为该原型成本。评价表按平台、任务和测量条件记录数据。

家庭场景以独立取物、照护介入、持续使用、适配成本和愿付价格评价使用价值。20户深访、5户走访、2户受监督共创及至少1份付费意向为场景验证目标。

## 10. 工程入口与方法来源

随附工程提供手部与目标输入、可选手套、时序意图基线、确认撤回、参考四轴取放、Mock与JSONL控制桥、日志及评价。打开demo/index.html可查看8类合成观测回放，执行python -m roboflex demo可运行相应软件流程。连续全身优化器和平台专用驱动由对应研究平台承载。

项目结合连续移动操作合作研究，将可靠性感知的时空规划与相位控制接入意图驱动取物任务。本项目依托合作研究基础开展场景应用，方法及合作研究出处见method_sources.md。连续操作相关论文尚未见刊，相关专利进展随正式文件更新。
