# 工程说明与运行范围

知意随行以GPT-6理解图像和用户意图，由任务管理组织目标与步骤，动作策略、时空全身规划及相位控制衔接执行。连续移动操作合作研究的方法出处见method_sources.md。

随附工程用于运行和检查交互与参考取放流程，包含MediaPipe关键点、ArUco目标、可选手套输入、时序支持分数、共享自主状态机、四轴参考IK、Mock与JSONL桥接、日志和测试。连续全身优化器和平台专用驱动由对应研究平台承载。

demo/index.html与python -m roboflex demo使用合成观测，展示候选目标、确认、撤回及执行状态变化。四轴动作序列的COMPLETE对应指令序列完成，物理取放结果依据实际传感与视觉核验。工程不附带GPT-6调用凭证或VLA权重。

OpenCV与MediaPipe承担基础视觉工具功能。第三方模型和依赖保留各自许可，合作研究保留原始署名。项目代码使用AI辅助整理与开发，由团队理解、复核及调试。
