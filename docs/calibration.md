# 坐标、相机与参考机械臂标定

第一轮固定底盘，在同一受控桌面观察用户手部和贴有 ArUco 标记的测试物体。当前不包含移动底盘定位，也不包含远程手套朝向到另一视角物体的映射。

## 基座坐标与机械臂

基座坐标：X 向前，Y 向左，Z 向上，右手系，单位 mm。四轴参考 IK 的底座绕 Z 旋转；肩／肘／腕在竖直平面内运动。

`link1_mm/link2_mm` 是关节轴间长度；`tool_mm` 是腕轴到末端参考点的长度；`base_height_mm` 是肩轴高度。`tool_pitch_deg=-90` 表示末端向下。肩、肘、腕的角度定义见 `FourAxisIK.forward()`，需要与实际零位逐轴对应。

`home_mm` 是人工确认无碰撞且可达的初始末端姿态；程序要求收到的关节状态与其 IK 相符，不会自动盲目归零。`handoff_mm` 是托盘放下时末端中心，不是人的手掌位置。`Target.position_mm` 同样是**夹取时末端参考点**，不是物体底面或标记中心。

## 相机配置

`camera_calibration` 字段格式如下。`FX/FY/CX/CY` 等占位需要替换为实测数值；此段用于说明，不是可直接运行的 JSON：

```text
camera_calibration:
  camera_matrix: [[FX, 0, CX], [0, FY, CY], [0, 0, 1]]
  dist_coeffs: [K1, K2, P1, P2, K3]
  T_base_camera: 4×4 齐次变换矩阵
  image_size: [实测宽度, 实测高度]
  max_reprojection_error_px: 2.0
```

`T_base_camera` 把相机坐标中的毫米点转换到机器人基座毫米坐标：

```text
p_base = T_base_camera @ [p_camera_x, p_camera_y, p_camera_z, 1]
```

先用棋盘格等方法得到相机内参与畸变，再用多个已知基座坐标点／标定板求外参，并通过未参与标定的点检查误差。程序会验证刚体变换、正焦距、图像分辨率与重投影误差，但这不能代替真实空间误差验证。若移动相机、修改分辨率、移动底盘或重新安装机械臂，需要重新核对相应变换。

每个目标配置：

```text
"0": {
  "label": "cup",
  "marker_size_mm": 实测标记黑色方形边长,
  "marker_to_grasp_mm": [DX, DY, DZ],
  "grip_mm": 经适配的闭合宽度
}
```

`marker_to_grasp_mm` 是标记坐标系内，从标记中心到期望末端夹取点的偏移。OpenCV IPPE_SQUARE 角点顺序为左上、右上、右下、左下，局部坐标依次 `(-s/2,+s/2,0)`、`(+s/2,+s/2,0)`、`(+s/2,-s/2,0)`、`(-s/2,-s/2,0)`。标记必须牢固固定在物体上，其偏移随安装变化而变化。

单平面标记存在视角、遮挡和姿态歧义风险，第一版应用于固定朝向、经过适配的物品。需要任意姿态抓取时，应增加 RGB-D、抓取姿态估计与多视角验证，不能仅靠这份四轴参考 IK。

## 工程边界

规划器检查的是末端点路径、静态禁入盒、关节范围和速度。它没有根据全臂连杆体积检测碰撞，也没有检测用户身体／动态障碍物。关节插补之间的实际末端路径由实机控制器决定；本包细分直线并提供关节端点，仍需在仿真模型和实机空载中核对。家庭交付还需要本地限位、物理停止、夹持力与抓取状态等反馈。

完成实测后再在自己的配置文件设置 `calibration_verified=true`；仅修改这一布尔值不会完成标定。
