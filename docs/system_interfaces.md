# 知意随行：模块接口与任务状态

## 1. 接口目标

接口连接GPT-6语义理解、任务组织、动作策略、全身规划与反馈控制，使同一任务目标在不同模块与平台之间保持一致。所有动作关联目标身份、时刻和任务步骤，反馈携带执行状态与完成证据。

以下为整体架构的模块契约。随附工程对应字段及JSONL报文见roboflex/types.py和docs/protocol.md，适配器负责架构契约与实际协议之间的映射。

## 2. 公共字段与单位

| 字段 | 含义 |
|---|---|
| schema_version | 消息与动作定义版本 |
| task_id / step_id | 整体任务与当前步骤 |
| seq / timestamp | 消息序号与采样或生成时刻 |
| frame_id | 空间坐标系 |
| target_id / target_version | 目标身份及当前有效版本 |
| valid_until | 本次输出的有效期 |
| source / validity | 数据来源、传感质量与可用性 |

时间采用统一单调时钟或经过同步的设备时基，保留采集和到达时刻以检查延迟。空间数据标明map、base、camera或tool坐标系，以及变换的版本与时间。

整体接口采用米、弧度与秒。参考四轴工程采用毫米和角度，单位在适配器集中转换。图像坐标、深度与三维位姿分别标明语义。

## 3. 模块契约

| 契约 | 输入或来源 | 主要字段与输出 | 消费者 |
|---|---|---|---|
| SceneState | 相机、本体与可选手部传感 | 图像引用、物体ID与位姿、手物关系、可见性、传感质量 | GPT-6理解、意图融合、任务与规划 |
| SemanticTaskProposal | GPT-6理解结果 | 目标候选、语义步骤、关系约束、待确认项 | 意图融合与任务管理 |
| IntentState | 连续观测与用户交互 | 目标支持、动作阶段、确认、无意图与撤回 | 任务管理 |
| TaskSpec | 目标确认与语义步骤校验 | 已绑定目标与交接点、步骤依赖、前置及完成条件、恢复范围 | 动作策略与规划 |
| ActionCandidate | VLA或几何动作策略 | 动作类型、向量定义、参考坐标、时域、目标版本与有效期 | 适配器与全身规划 |
| MotionReference | 时空全身规划 | 底盘与关节轨迹、阶段时长、任务相位与约束 | 相位反馈控制 |
| ExecutionFeedback | 控制器与设备反馈 | 接收、执行、完成证据、误差、物品状态、失败与停止原因 | 任务管理与重规划 |

GPT-6输出先形成语义任务建议，由任务管理绑定到场景实体并检查步骤条件，再进入动作执行链。三维目标位置由深度和标定模块提供。动作策略候选通过坐标、有效期、可达性与平台动作检查后形成规划参考。

## 4. 动作适配

ActionCandidate必须声明动作空间，例如关节位置、关节速度或末端位姿增量，并给出维度、单位、控制周期与参考坐标。适配器据本体模型完成映射，规划层检查底盘运动学、机械臂可达性、关节范围与场景约束。

模型输出、动作适配和执行控制采用一致的动作含义。更换模型或硬件时，固定测试任务检查目标绑定、动作方向、单位、目标版本、超时和停止，再评价任务结果。

## 5. 任务状态与推进

整体任务包含观察、确认、规划、执行、核验、恢复、完成、取消和故障状态。任务账本持久记录task_id、step_id、目标版本、已完成步骤和失败原因。

- 观察阶段保持候选目标与无意图状态。
- 确认后锁定目标和交接点，再检查步骤与可达性。
- 执行期间更新观测和误差，按相位调整参考与反馈。
- 完成证据成立后推进当前步骤，并衔接后续任务窗口。
- 恢复阶段重新检查意图、目标与场景版本，再决定重试或接管。
- 急停独立锁存，设备明确复位并核验状态后恢复。

随附工程中的OBSERVING、CONFIRMING、EXECUTING、COMPLETE、CANCELLED、FAULT通过适配器与上述任务状态衔接。其中COMPLETE记录参考动作序列完成，物理任务验收继续使用设备或视觉证据。

## 6. 关键事件

| 事件 | 系统处理 | 后续条件 |
|---|---|---|
| 观测过期或跟踪丢失 | 暂停推进并更新场景 | 恢复有效观测与目标定位 |
| 目标移动或版本变化 | 使旧候选失效，更新目标与规划 | 当前意图、可达性与新版本一致 |
| 抓取未成立 | 保留当前步骤与失败记录 | 受限重试或接管 |
| 局部误差超出余量 | 结束局部补偿并请求重规划 | 新参考满足平台与任务约束 |
| 用户撤回 | 停止本次任务并保持物品受控 | 新的有效意图与确认 |
| 急停或设备故障 | 停止并锁存故障状态 | 按硬件流程复位并核验机器人与物体 |

夹持保持、受控放置与制动方式由硬件配置确定。通信ACK、指令完成和物理任务完成分别对应不同事件字段。
